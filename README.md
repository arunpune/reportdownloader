# Test Report Portal

A centralized web portal for receiving, storing, searching, and downloading original Excel test reports generated by LabVIEW.

The system automatically detects new test report files placed in a designated folder, processes their metadata, stores the report information in a local SQLite database, and makes the reports available through a Flask-based web portal.

---

## Overview

The Test Report Portal provides a simple interface for customers/users to:

- View available test reports
- Search reports by Recipe Name
- Filter reports by Date
- Search reports using Serial Number
- View the original report file name
- View the test generation time
- Download the original Excel report
- Navigate through large numbers of reports using pagination

New reports can be added to the watched folder without manually entering them into the portal.
